# Claude_chaxun

脚本查重工具：检查今天写的脚本，有没有和 **最近两天的脚本** 或 **指定脚本** 重复。

有两种用法：

- **在线版**：https://z997000734-svg.github.io/Claude_chaxun/ ，手机、电脑用浏览器直接打开，不用登录。脚本库存在各自设备的浏览器里，换设备用“导出备份 / 导入备份”。
- **网页版（本地）**：用浏览器直接打开 `index.html`，粘贴或上传脚本就能查，结果里会把重复的句子标黄。历史脚本保存在当前浏览器里，换电脑或清理浏览器数据前请先点“导出备份”。
- **命令行版**：`script_checker.py`，只需要 Python 3.8+，不用装第三方库。

## 网页版用法

1. 打开 `index.html`
2. 在“历史脚本库”里批量上传以前的脚本（文件名带日期，如 `2026-11-01-保温杯.txt`，就会按这个日期归档）
3. 把今天的脚本粘贴到 ①，需要和某一篇单独对比的话，粘贴到 ② 或者在脚本库里点“指定对比”
4. 点“开始查重”；查完点“保存到脚本库”，以后查重时也会拿它来对比

## 怎么放历史脚本

把以前的脚本放到 `scripts/` 目录（也可以用 `-d` 指定其他目录）。工具按下面的顺序判断每个脚本是哪天的：

1. 文件名里的日期，例如 `2026-11-01-保温杯.txt`、`20261101_口播.txt`
2. 日期文件夹，例如 `scripts/2026-11-01/xxx.txt`
3. 以上都没有，就用文件的修改时间

"最近两天"指昨天和前天，不算今天。

## 用法

```bash
# 和最近两天的脚本查重
python script_checker.py 今天的脚本.txt

# 和指定脚本对比（-t 可以写多次）
python script_checker.py 今天的脚本.txt -t 参考脚本.txt

# 两种一起做
python script_checker.py 今天的脚本.txt -t 参考脚本.txt
```

常用参数：

| 参数 | 说明 | 默认 |
|---|---|---|
| `-t / --target` | 指定对比的脚本 | 无 |
| `-d / --dir` | 历史脚本目录 | `scripts` |
| `--days` | 和最近几天的脚本比，0 表示不比 | 2 |
| `--threshold` | 句子相似度达到多少算重复 | 0.8 |
| `--min-len` | 少于多少字的句子不参与查重 | 6 |
| `--fail-above` | 重复率超过该值时返回码为 1 | 无 |
| `--json` | 输出 JSON | 关 |

## 结果怎么看

- **重复率**：重复句子的字数占全文字数的比例，是主要指标（≥50% 高度重复，≥20% 部分重复）
- **全文相似度**：两篇文本整体的相似程度
- **片段重合**：当前脚本里的三字片段有多少在对方脚本里出现过，改写后的内容也能查出来

标点和空格会被忽略，比较时英文不区分大小写。文件支持 UTF-8 和 GBK 编码。
